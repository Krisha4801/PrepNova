## 3. Ownership Verification Key

- **High**: The member's personal Git account directly authored the commits in the repository log matching their technical domain, corroborated by documentation and source code.
- **Medium**: Strong evidence from repository metadata (e.g., repository creator, commit logs in related tiers, or explicit co-authorship), supported by project status reports.
- **Unverified (Git) / High (Academic Role)**: The code exists, functions, and was audited in the codebase; the member was formally assigned and tracked in university status reports (`7_PrepNova_BiWeekly_Status_Report_2_Code.tex`), but their contributions were committed to GitHub via another teammate's machine/account.
